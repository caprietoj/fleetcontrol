iPad (7.ª generación u otros, iPadOS 13 o superior)

          
El registro de iPad necesita HTTPS. Este panel se está usando con http://, así que el iPad mostrará “Ocurrió un error desconocido”. Publica el servidor con un dominio y HTTPS (Caddy lo hace automáticamente, ver README) o usa el registro manual de abajo.

          

            

            

              
    
                
  1. En el iPad, abre la Cámara y apunta a este código (o abre el enlace en Safari).
    2. 
                
  2. Toca Descargar perfil y luego Permitir.
    3. 
                
  3. Ve a Ajustes → Perfil descargado → Instalar e ingresa el código del iPad.
    4. 
                
  4. Safari muestra “iPad registrado” y el equipo aparece en Dispositivos.
    5. 
              

              

            

          

          
Los iPad quedan en el inventario y se les pueden cerrar las sesiones de Google Workspace. Para borrarlos, instalarles apps o bloquearlos de forma remota se necesita un MDM de Apple (ver README).
